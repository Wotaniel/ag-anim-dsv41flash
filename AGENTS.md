# AGENTS.md — правила работы с проектом

Проект: анимация App Store In-App Event «AdGuard v5 is here» (AG-60517).
Два формата — карточка 16:9 (1920×1080) и деталка 9:16 (1080×1920), луп 10 с.
Конечный потребитель — **человек, который анимирует в Keyshape руками**.

## Архитектура — не ломать

- **`tools/build.py` — единственный источник истины.** Ключи заданы спеками в секундах;
  из них генерируются оба `.keyshape` и `preview/animation-data.js` (браузерный плеер).
  Превью и Keyshape обязаны совпадать 1:1 — иначе пропадает смысл превью.
- `tools/fetch_pieces.py` — выгрузка кусков из Figma по REST (ветка `HAd3I2CYWl0dzYKKN5cKiC`).
  Перезапускать только при изменении макетов; он перезапишет `assets/meta.json`.
- `tools/validate.py` — обязательная проверка перед сдачей.

## Формат Keyshape — проверено по спеке (keyshapeapp.com/file-format)

- **`abs-key-times` — СЕКУНДЫ**, `ks:playRangeIn/Out` — **МИЛЛИСЕКУНДЫ**. Единицы смешанные.
- **`timing-functions` — ровно на 1 меньше числа ключей**, иначе файл ведёт себя непредсказуемо.
- **`animateMotion path` — абсолютный**, в координатах родителя, и **начинается в позиции объекта**
  (`path[0] == translate` группы). Относительные оффсеты → объект стоит не там.
- **`scale`/`rotate` крутятся вокруг позиции группы** (пивот = `translate`), контент внутри
  нарисован со сдвигом `-пивот`. Меняешь пивот — пересчитывай motion-ключи.
- `values` для scale — пары `x,y` через запятую. `repeat-end="indefinite"` для лупа.
- **`<filter>` Keyshape не поддерживает** (только shorthand `filter`). Блюр Figma заменён
  радиальным градиентом — не возвращать `feGaussianBlur`.

## Грабли, которые уже стреляли

1. **`fill="none"` с корневого `<svg>` куска теряется** при вставке внутренностей в документ.
   Без него фигуры без явного `fill` (обводки чипов) заливаются **чёрным**. Обёртки кусков
   помечены `fill="none"` — не убирать.
2. **Текст Figma экспортируется по ink-bbox** (`absoluteRenderBounds`), а не по bbox фрейма.
   Позиционировать по `absoluteBoundingBox` нельзя — текст съедет вверх/вбок.
   `fetch_pieces.py` выбирает origin по совпадению размера с viewBox.
3. **REST-экспорт сплющивает группы**: части персонажа отдельными слоями не выгрузить.
   Дробить — только через Figma (создать узлы) или вручную в Keyshape.
4. **`<radialGradient>` по умолчанию в objectBoundingBox**: `cx/cy/r = 0.5/0.5/0.5`.
   Если задать `gradientUnits="userSpaceOnUse"` с `r="1"` — градиент схлопнется в точку.
5. **Бесшовный луп**: первый и последний ключ каждого канала должны совпадать; блики
   возвращаются в стартовую позицию на невидимом участке (последний сегмент), а не прыжком.

## Структура документа

```
svg (viewBox, ks:playRangeOut=10000)
  defs (glowGrad, glintHalo, ksclip)
  rect #000
  g clip-path
    Camera        ← Position (motion) + Scale; внутри всё остальное
      Glow        ← Opacity + Scale
      Character   ← Scale (дыхание)
      Glint-crown ← Position + Scale + Opacity
      Glint-sword ← Position + Scale + Opacity
      Badge / Title / Subtitle / Chip-*  ← статичны, только translate
```

UI лежит **внутри** камеры: наезд двигает всю композицию, как настоящая камера.
Порядок слоёв = z-порядок из Figma (в 16:9 персонаж поверх чипов, в 9:16 — UI поверх персонажа).

## Тайминг (не менять самовольно)

| Время | Фаза |
| --- | --- |
| 0.0–2.6 | наезд камеры 1.000 → 1.026 (16:9) / 1.020 (9:16) |
| 2.6–4.2 | пауза; блик на короне ≈3.2 |
| 4.2–6.0 | наезд 2 → 1.052 / 1.042 |
| 6.0–7.0 | пауза; блик на мече 16:9 ≈7.5, 9:16 ≈6.7 |
| 7.0–10.0 | медленный отъезд до 1.000 |
| всё время | дыхание персонажа: 2 вдоха за луп (0–2, 5–7), свечение в такт |

## Верификация перед сдачей

1. `python3 tools/build.py && python3 tools/validate.py` — оба OK.
2. Скриншот-сверка кадра t=0 с рендером Figma (`assets/<frame>/_frame.svg` → Chrome):
   расхождение только по сглаживанию текста (mean abs diff < 2).
3. Проверка шва лупа: t=9.999 и t=0 должны быть пиксельно идентичны.
4. Глазами — `preview/` кадры на ключевых фазах (3.2 блик короны, 6.0 макс. наезд, 7.5 блик меча).

Скриншот кадра:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu \
  --hide-scrollbars --force-device-scale-factor=1 --window-size=1920,1080 \
  --virtual-time-budget=3000 --screenshot=/tmp/f.png \
  "file://$PWD/index.html?still=1&t=3.2&only=16x9"
```

## Процесс

- Правки руками в Keyshape — ценность: если пользователь что-то поправил, **не пересобирать**
  поверх молча; сначала перенести правку в `tools/build.py`.
- Не менять раскадровку «по догадке»: жалоба «слишком дёргано» ≠ «убери фазу».
